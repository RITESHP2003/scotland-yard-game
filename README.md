# Scotland Yard - Digital Board Game
A pass-and-play digital version of the classic Scotland Yard detective board game.
Play on any device — phone, tablet, or desktop.

## Play
Visit: https://RITESHP2003.github.io/scotland-yard-game/

## Features
- Faithful recreation of the classic board game rules
- Pass-and-play for 3-6 players on a single device
- Works offline (PWA)
- Touch-friendly pan/zoom map
- Mr. X travel log with deduction mechanics
