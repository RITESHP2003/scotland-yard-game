How to Play

🎯 Objective

Mr. X must evade capture for 24 turns. Detectives must catch Mr. X by landing on the same station.

🗺️ The Board

199 stations connected by three transport types:

Taxi — Short routes between adjacent stations
Bus — Medium routes across neighborhoods
Underground — Long routes between 14 key stations
Black Ticket — Mr. X only: any transport + boat

🎮 How Turns Work

Mr. X moves first (secretly), then each detective. Tap a highlighted station to move there, choose your ticket type.

Pass and Play: Hand the device between turns. Mr. X's position stays hidden!

🕵️ Mr. X's Secrets

Travel Log: Detectives see which ticket Mr. X used each turn, but not the destination.

Reveal Turns (3, 8, 13, 18, 24): Mr. X must show their position!

Double Move: Move twice in one turn (2 available).

Black Tickets: Hide which transport you used (5 available).

🏆 Winning

Detectives win if any detective lands on Mr. X's station.

Mr. X wins if all detectives are stranded or 24 turns pass.
